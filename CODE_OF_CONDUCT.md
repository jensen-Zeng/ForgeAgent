# Code of Conduct

## Our standard

ForgeAgent contributors are expected to communicate respectfully, welcome constructive disagreement, and focus discussion on observable behavior, evidence, and project goals. Harassment, discrimination, personal attacks, deliberate disruption, and publication of private information are not acceptable.

## Scope

This standard applies to repository discussions, issues, pull requests, reviews, and other spaces where a person represents the project.

## Reporting

For conduct concerns, contact the maintainer through the private reporting channel listed on the maintainer's GitHub profile. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

Project maintainers may edit or remove contributions and restrict participation when behavior violates this standard. Reports will be reviewed in context and handled as privately as practical.
