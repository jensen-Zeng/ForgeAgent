# ADR-0005：容器作为按风险自动选择的第二道隔离

- 状态：Accepted，2026-07-27 修订（宿主验证待完成）
- 日期：2026-07-26

## 决策

容器默认禁网、非 root、只读根文件系统、删除 capabilities、限制资源，仅挂载目标工作区；禁止 privileged、Docker Socket 和主目录整体挂载。命令默认使用 `auto` 路由：`SAFE` 本地、`REVIEW` 审批后容器、`DENY` 拒绝。也保留显式 `docker` 全量隔离和 `local` 兼容模式。

## 影响

容器降低误操作和仓库恶意代码风险，但不等于虚拟机。自动模式不会在 Docker 缺失时降级本地。当前宿主缺少 Docker/WSL，实际构建、权限行为和逃逸测试仍是明确阻塞项。
