# ADR-0003：命令使用窄白名单和分级审批

- 状态：Accepted
- 日期：2026-07-26

## 决策

命令必须以 executable/arguments/cwd 结构传入且禁用 Shell。测试、静态检查和只读 Git 归类为 `SAFE`；格式化与包管理归类为 `REVIEW`；网络、提权、删除、Shell 和 Git 历史操作归类为 `DENY`。默认 `auto` 模式把 `SAFE` 留在本地、把人工确认后的 `REVIEW` 强制送入 Docker，并在 Docker 不可用时失败关闭。

## 影响

策略易解释且默认安全，但会拒绝部分合法命令。模型不能通过参数伪造风险、审批或执行后端。新增命令必须带风险分析、路由预期和测试。
